2. Haz clic en New repository y nómbralo ap-academy-web; elige Public.
3. En el repositorio, selecciona Add file > Upload files.
4. DESCOMPRIME ESTE ZIP y sube index.html, soporte.html, privacidad.html, terminos.html y la carpeta assets. No subas el ZIP sin extraerlo.
5. Haz Commit changes.
6. Abre Settings > Pages. En Build and deployment, selecciona Deploy from a branch; Branch main; Folder /(root); Save.
7. Espera la publicación y abre https://TU_USUARIO.github.io/ap-academy-web/
8. Comprueba que las cuatro páginas abren sin iniciar sesión, incluso en una ventana de incógnito.
